# Quest Progression

Quest book title: **Aeronautics Workshop**

Create these chapters in FTB Quests. The optional branches can be skipped; each chapter should gate its rewards behind the listed completion tasks. Avoid granting bulk materials that bypass the engineering progression.

## 1. First Principles

- Gather andesite, iron, copper, zinc, and logs.
- Craft a hand crank and a water wheel.
- Build a small rotational power line and demonstrate a working mechanical press.
- Reward: basic Create building materials.

## 2. A Reliable Workshop

- Build a millstone, mechanical mixer, basin, and deployer.
- Automate andesite alloy and precision mechanisms.
- Make a compact, serviceable factory with a clutch or gearshift.
- Reward: belts, shafts, and storage components.

## 3. Logistics and Storage

- Craft Tom's Simple Storage inventory connector and terminal.
- Connect at least three inventories and verify item access from the terminal.
- Build a safe overflow or filtered output for one automated farm.
- Reward: additional connectors and labels.

## 4. Rails and Exploration (optional addon branch)

- Build a powered rail line with a station and a working schedule, if Steam 'n' Rails is installed.
- Establish a small remote outpost with a storage link or transport plan.
- Reward: rail components.

## 5. Aeronautics Foundations

- Complete the Aeronautics assembly and control tutorials using the installed mod's actual blocks.
- Build a minimal stable test vehicle and verify assembly, steering, and safe disassembly.
- Perform a short test flight or movement run without carrying a factory.
- Reward: decorative vehicle materials.

## 6. Flightworthy Craft

- Build a controlled flying craft with a dependable power source and control system.
- Add a cargo solution and return safely with gathered resources.
- Demonstrate a landing and disassembly/reassembly cycle.
- Reward: advanced Create components.

## 7. Automated Expedition

- Add a deployer or other suitable machine to the vehicle only after validating the small craft.
- Complete an expedition objective and bring back a specified set of resources.
- Keep the vehicle's moving assembly compact; test performance before adding detail.
- Reward: addon-specific materials for installed, compatible addons.

## 8. Master Engineer

- Build one end-to-end automated production chain using Create.
- Document the machine's inputs, outputs, and shutoff method with signs or a written book.
- Complete a final Aeronautics build challenge: transport a cargo load between two marked locations and return.
- Reward: cosmetic completion items, not progression-skipping machinery.

## Optional addon quests

Only add a branch when that addon is actually present. Create: Big Cannons can have a safe range-test branch; Create Crafts & Additions can have a power-conversion branch; New Age can have a generation branch; Slice & Dice can have a food-processing branch; Enchantment Industry can have an enchanting automation branch. Use the current in-game recipes as task requirements rather than hardcoding recipe assumptions across addon versions.
