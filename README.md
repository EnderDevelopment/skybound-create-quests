# Minecraft Create: Aeronautics Modpack Guide

Skybound Create Questpack is a Minecraft modpack guide for building a performance-conscious Create: Aeronautics experience on Windows 11, with a guided quest progression, networked storage, compatible Create addons, and practical performance settings. It targets a 16 GB RAM PC and documents how to assemble and check a NeoForge 1.21.1 setup; it is a guide, not a prebuilt modpack or imported quest file.

## Install

1. Install Minecraft Java Edition 1.21.1 with NeoForge, using a launcher that supports NeoForge modpacks.
2. Use Java 21, 64-bit, unless your launcher provides a suitable Java runtime.
3. Download Create, Sable, Create: Aeronautics, FTB Quests, FTB Library, and Tom's Simple Storage Mod from their official project pages. Select only files that explicitly support Minecraft 1.21.1 and NeoForge, including required dependencies.
4. Add optional Create addons and performance mods only when their official release files match your Minecraft version and loader. The guide's suggestions are candidates, not confirmed compatible inclusions.
5. Allocate 6 GB of RAM in the launcher. Start a disposable test world before using an existing save.

## Use

1. Begin with the progression in QUESTS.md, which covers Create basics, workshop automation, storage, Aeronautics, expeditions, and an end-to-end engineering challenge.
2. Install FTB Quests and FTB Library to use an in-game quest book. QUESTS.md describes quest goals but does not include importable FTB Quests data.
3. Connect at least three inventories to a Tom's Simple Storage network and verify access from its terminal.
4. For smoother exploration, consider using Chunky to pregenerate a modest area, such as a 3,000-block radius, before traveling. Pregeneration does not eliminate the cost of live chunk generation.
5. Start with render distance 8-10, simulation distance 5-6, and shaders off. Adjust settings if performance or available memory requires it.
6. Back up worlds before updating Minecraft, NeoForge, Create, Aeronautics, or addon versions. For multiplayer, match the server and client content mod versions.
